# 青甘大环线 · 8 天 7 晚冬季自驾

[打开行程网页](https://zhiyuejoey.github.io/qinggan-trip/)

这份行程用于 2027 年寒假青甘大环线自驾。用手机或电脑浏览器打开即可查看。

- 交互地图和 8 天 7 晚逐日时间表
- 沿线 32 个备选景点，可按自己的计划勾选
- 1 月底沿线气温参考、冬季自驾注意事项和沿线美食
- 穿衣与观星装备勾选清单

在 iPhone 上，可用 Safari 打开网页，再通过「分享 → 添加到主屏幕」保存入口。景点和装备的勾选状态保存在当前浏览器中，各设备独立保存。地图和在线路线服务需要联网。

## 更新行程

网站由 GitHub Pages 从 `main` 分支的根目录发布。修改或替换根目录的 `index.html` 后提交到 `main`。部署完成后，刷新原网址即可查看新版。
