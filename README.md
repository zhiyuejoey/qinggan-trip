# 青甘大环线 · 8 天 7 晚冬季自驾攻略

[打开行程网页](https://zhiyuejoey.github.io/qinggan-trip/)

这份行程用于 2027 年寒假青甘大环线 2 人冬季自驾（约 2,400 km，零回头路直抵冷湖观星）。用手机或电脑浏览器打开即可查看：

- **交互地图与路线补给**：8 天 7 晚高德中文/OSM 地图路线、D4 冷湖观星（避开 2027.1.22 满月及极寒防结露实拍技巧）、沿线加油站分布与无信号盲区速览
- **沿线 36 个备选景点库**：支持分段筛选、关键词搜索、恢复默认、一键定位与高德导航/小红书直跳，附 2026–2027 冬季参考票价、营业/停检时间与实操避坑提示
- **8 天 7 晚逐日时间表**：按 1 月底沿线日出日落时间倒推，覆盖 D8 峨堡镇网红雪山公路 & 俄博岭垭口及岗什卡雪峰连心湖轻游规划，逐日补充加油与信号、暖气/地库住宿选址、景区预约规则及雪天封路 B 计划
- **气温、行前倒计时与 26 项装备清单**：沿线日照与温差参考、春运前夕 T-30 至出发前 1 天准备节点，以及穿衣分层、防晒保湿、观星保暖、自驾应急与药品补给勾选清单
- **冬季专项注意、门票速查、预算与救援**：9 条冬季自驾硬核注意事项、11 大核心景区淡季门票/预约/停检速查表（含张掖七彩丹霞北门改造走西/东门、岗什卡连心湖摆渡车提醒）、2 人淡季地面预算参考、应急救援一键拨号及沿线美食建议

在 iPhone 上，可用 Safari 打开网页，再通过「分享 → 添加到主屏幕」保存入口。景点和装备的勾选状态保存在当前浏览器中，各设备独立保存。地图和在线路线服务需要联网。
